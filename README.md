# Stroke Prediction using Logistic Regression 🩺  

Predicting the likelihood of a patient suffering a **stroke** based on health indicators using **Logistic Regression** and **scikit-learn**.  
This project was completed as part of my **ENG4200 Machine Learning Coursework**, focusing on experiment design, performance analysis, and interpretability rather than raw accuracy.

---

## 🚀 Overview

Using the [Stroke Prediction Dataset](https://www.kaggle.com/datasets/fedesoriano/stroke-prediction-dataset), this project explores how machine learning can help identify key factors influencing stroke risk.  
The workflow includes:
- Data exploration and preprocessing (handling imbalance, encoding, scaling)
- Logistic regression modelling and validation
- Performance evaluation (Accuracy, F1-score, ROC–AUC)
- Visualisations for interpretability and insights

---

## 🧠 Key Insights

- **Age**, **hypertension**, and **heart disease** were among the strongest predictors of stroke risk.  
- The logistic regression model balanced **predictive power** and **computational efficiency**.  
- Highlighted the importance of **data preprocessing** and **balanced datasets** in healthcare prediction.
